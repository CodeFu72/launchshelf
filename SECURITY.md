# Security reporting

LaunchShelf is early software. Security fixes target the current `main` branch;
older development snapshots do not have a separate maintenance guarantee.

Use the repository's **Security → Report a vulnerability** option for private
reports when available. If the option is unavailable, open an issue asking for a
private reporting channel without including vulnerability details or sensitive data.

Include the affected commit, a minimal reproduction, impact and any proposed fix.
Never include credentials, customer documents or your personal project registry.

Project commands can execute code under your user account. Review detected commands
and use project folders you trust. LaunchShelf does not sandbox launched programs.
