# Roadmap

First version: project intake, reviewed commands, launch/build logs, source/docs
shortcuts, Git status and managed desktop entries.

Before a packaged release: test a clean install on other Linux environments,
prepare a tagged downloadable build and record an actual demo. The source is
available under MIT; public source availability does not imply broad compatibility.

Later candidates: drag/drop intake queue for multiple folders, richer detectors,
bounded build cancellation, persistent run summaries, custom app icons, portable
registry import/export and optional Omarchy submenu synchronization.

This is a roadmap, not a claim that future features are implemented.
