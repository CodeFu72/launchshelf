# LaunchShelf

LaunchShelf is a public Linux desktop workshop for locally built applications.
Keep the Rust core independent of the native egui interface. Persist a versioned
registry outside the source repository. Never execute detected project commands
without the user reviewing and saving them. Commands use executable/argument
parsing, not implicit shell evaluation; shell commands require an explicit shell.

Keep personal registries, credentials, proprietary assets and customer documents
out of Git. Use synthetic fixtures and portable paths in public examples. Target
Linux with optional Omarchy integration; never edit /usr/share/omarchy.

Test detection, quoted command handling, storage integrity, failed launches and
desktop registration. Report support limits accurately. Do not publish code,
releases or social posts until Kirk has reviewed the prepared result.

Keep Obsidian notes under OMARCHY - LINUX/LaunchShelf current at milestones,
following Kirk's global documentation preference. The private vault is not part
of this public repository.
